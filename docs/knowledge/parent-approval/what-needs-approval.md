# What is gated and why

| Change | Gate | Why |
| --- | --- | --- |
| A new exercise | approve before the keeper sees it | youth resistance training should be designed and supervised by qualified people, with technique learned before load is added[^lloyd-2014] |
| More load, sets, reps, jumps or sessions | approve before use | progression for youth is gradual and technique-led[^lloyd-2014] |
| Return after pain or injury | parent clearance before any training | return to sport is a staged, shared decision, not a single end-point[^ardern-2016] |
| A change to the weekly plan | approve before use | a plan change alters total load the same way |
| Sharing, leaderboards, anything leaving the household | approve before use, and off by default | the regimes surveyed agree on protective defaults and sharing only when needed, with parental consent for disclosure to others[^baseline][^ico-aadc][^coppa-2025][^opc-youth] |

# What does not need approval

- Repeating an already-approved item at the approved dose, the way re-downloads skip Ask
  to Buy.[^ask-to-buy]
- Doing less: skipping a set, ending early, taking a rest day.
- Reporting pain, which must never wait on anyone.

# Return after pain

The Bern statement treats return as a continuum alongside rehabilitation, with the athlete
taking part in the decision and risk judged by the people around them.[^ardern-2016] For
this app that means: the parent clears, the keeper's view is recorded, and the return runs
through approved, reduced steps rather than a jump back to the old plan.
