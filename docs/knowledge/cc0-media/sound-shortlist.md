# How to read this list

- Licences were read on each file's own page (Freesound) or on the pack page and the
  pack's licence file (Kenney) on 2026-11-18 (UTC); see
  [Freesound](/cc0-media/freesound-cc0.md) and [Kenney](/cc0-media/kenney-audio.md).
  Re-check the page when a file is adopted and record that date in `content/credits.json`.
- Lengths are as the Freesound page states them. Kenney lengths were measured from
  repackaged copies of the packs and are approximate.
- **Character notes for Freesound files come from the uploader's description; Kenney
  notes come from file names and pack tags. Nothing here has been listened to yet.** The
  owner and the reviewer listen to each candidate before adoption (see the checks below).
- Loudness is not yet measured; every adopted file is normalised to the targets in
  [stored format](/cc0-media/sound-format.md), so source loudness only matters for
  noise and clipping.

# Rules the shortlist follows

- **Safety stop and pause are calm.** No error buzzer, alarm, siren or falling "fail"
  tone, and no celebration. They play quieter than the functional cues, never louder.
  Kenney's `error_*` files are excluded for this reason. A safety stop sounds different
  from rest so the two are never confused.
- **Functional cues carry across a room**: start, 3-2-1, switch and rest are short, with
  a clear attack. Celebration sounds (XP, session done) stay short and are never louder
  than the cues.
- **Each moment has its own sound**; no two moments share a file.
- **Clean room (AC4):** every candidate is a generic cue (a whistle, a beep, a chime, a
  bowl, a short major-key sting). None was chosen for resembling the reference app's
  sounds or jingles, and none is described by comparison with them. A candidate that
  turns out, on listening, to recall the reference app or any other product's signature
  sound is dropped.

# Checks before adoption

1. Download the original from the page above (Kenney's own zip for Kenney files) and
   re-read the licence on that page.
2. The owner and the reviewer listen to each candidate on the iPad, from across a room,
   and confirm the character note and the clean-room rule.
3. Trim, fade, normalise and encode it as the [stored format](/cc0-media/sound-format.md)
   says; place it under `content/sounds/` with a `content/credits.json` entry (author,
   page, `CC0-1.0`, date checked, changes made).
