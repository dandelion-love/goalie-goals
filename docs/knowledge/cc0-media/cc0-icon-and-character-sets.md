# Licence as stated

| Set | Licence on its own page | Per-file difference | AI note | Exercise poses |
|---|---|---|---|---|
| Open Peeps | CC0, free for commercial and personal use[^open-peeps] | None; one licence for the set | None stated | Standing and sitting people only |
| Open Doodles | Free for any use, no credit or licence needed, from the same author as Open Peeps[^open-doodles] | None | None stated | Jumping (a star jump with a kick), running, sprinting, ballet |
| Health Icons | Public domain (CC0); no credit needed, editing allowed[^healthicons] | None | None stated | Run, walk, weights, exercise, yoga, in outline and filled styles[^healthicons-site] |
| Pinhead | CC0; seeded from other CC0 and public-domain map-icon sets[^pinhead] | Upstream sets are all CC0 or public domain | The project says its icons are made with no AI[^pinhead] | A person squatting, running, kicking a ball; 15 px map icons |
| Noun Project | Per icon: public domain, CC BY 3.0, or a paid royalty-free licence[^noun-terms][^noun-blog] | Yes: the licence is on each icon's page | None stated | Many exercise icons, but the plank icon checked showed a royalty-free licence[^noun-plank] |

Date checked for all: 2026-11-18. Open Peeps and Humaaans were already surveyed for character art; this page adds the sets above.[^earlier]

# Notes

- **Noun Project:** its search page offers no licence filter, its terms bar large-scale copying even of public-domain icons, and downloads need an account.[^noun-terms] Hundreds of its older CC0 icons are mirrored on Wikimedia Commons, where each page states the licence; that is the usable route.[^noun-commons]
- **Fit:** these sets suit interface icons, empty states and the parent or mascot character. None shows a plank, bridge, split squat, shuffle or dive.

# Verdict

**Open Peeps, Open Doodles, Health Icons and Pinhead pass** as CC0 sets, for icons and character art rather than exercise figures. **The Noun Project fails** as a direct source of exercise figures: the licence varies per icon and the one checked was not public domain. Its icons count only through a Commons page that states CC0.
