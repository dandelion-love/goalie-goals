# Summary

All three libraries are CC0 and made by the same illustrator. They are the best CC0
starting point for a human coach, because they are built to be recombined into new
people. None has a coach, a goalkeeper or a sports kit, so the coach's defining parts
(cap, whistle, gloves, a clipboard or a ball) must be drawn.

# Licences, as stated on each page (checked 2026-11-18)

| Library | Licence wording on its own page | Attribution |
|---|---|---|
| Open Peeps | "Free for commercial and personal use under CC0 License"; the page also calls it public domain[^open-peeps] | Not required[^cc0] |
| Humaaans | "CC0 Public Domain License", "free for commercial or personal use"[^humaaans] | Not required |
| Open Doodles | "Free for commercial and personal use. No need to credit", with a CC0 badge linking the CC0 deed[^open-doodles] | Not required |

The app's media Decision already names Open Peeps for mascot or parent art and gives a
credit for provenance anyway.[^media-decision]

# How each is built, and fit for a coach

| Library | Build | Formats | Fit |
|---|---|---|---|
| Open Peeps | Hand-drawn black line art; people built from swappable heads, faces, hair, bodies, arms, legs, poses (standing, sitting)[^open-peeps] | SVG and PNG; component files for design tools[^open-peeps] | Best base. Expressive faces cover calm, pleased and proud without any sad or pleading face. Line art must be restyled to the app's thick-stroke, flat-fill look. |
| Humaaans | Flat colour people built from parts (heads, bodies, legs), posable[^humaaans] | SVG; component files for design tools[^humaaans] | Closer to a flat game look. Faces are minimal, so less personality for a coach. |
| Open Doodles | A fixed set of 33 doodles, a few active (running, sprinting, jumping and kicking)[^open-doodles] | SVG, PNG, some GIF | Not modular; useful only as a pose reference for an active coach. |

# Limits

- No sport poses beyond a few running or kicking doodles, as the exercise-media research
  already found for exercise figures.[^figures]
- The libraries are widely used. A coach made only by recombining parts would look like
  stock art, so the coach needs its own drawn elements and colours to be original.
