# Licence model

Checked on 2026-11-18 (UTC).

- Each submission page shows a "License(s)" field, which can list more than one licence.
  Only submissions where CC0 is listed are in scope here.
- A submission is usually one archive with many files by one author, so the submission's
  licence covers each file in it. Some submissions are collections of other people's
  work: check that the author field names the creator, and that the archive holds no
  licence file that says otherwise.
- Comments on a page are not the licence; the field is.

# Fit

OpenGameArt adds little that Kenney and Freesound do not already cover for this app,
and its pages do not state per-file length or loudness. Use it when a shortlist slot has
no good Kenney or Freesound option, and record the submission page as the licence
source of every file taken from an archive.
