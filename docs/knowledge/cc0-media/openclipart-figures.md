> **Rejected for exercise figures.** The owner rejected Openclipart drawings for quality on 2026-11-18. This page is kept as the record of the survey; the exercise-media Decision lists Openclipart under never used.


# Licence as stated

- **Site-wide:** the sharing page says every upload is released under CC0 and that all clipart is public domain, including for unlimited commercial use. No credit is needed, though a reference is encouraged.[^share][^cc0]
- **Where it shows on a file:** a file page carries no licence block of its own; its footer links to the sharing page, labelled as 100% public domain.[^gk-dive]
- **Per file:** the licence does not differ by file, but provenance does. The site tags a file `pd_issue` when its licensing or source is in doubt.[^share] Some uploads are traced from period photos or prints: their tags name a year such as 1908, 1917 or 1919 and the style is "semi-realistic".[^gk-1908][^exercise-1][^track-field]
- **AI:** the sharing page says nothing about AI-generated images, and file pages carry no AI field.[^share] A file uploaded before 2022 predates common image generators; a later one needs a person's look before use.
- **Date checked:** 2026-11-18, on the site's own pages.

# Verdict

**Passes, per file.** The licence is clear and site-wide. Each file is still checked for a `pd_issue` tag; for a tag or style that says it was traced from an older image (an outline or silhouette serves as a pose reference only, and a traced figure that could identify a real person is not used); and for an upload date after 2022 (a person looks for signs of AI before use). Styles vary from file to file, so files serve as pose references for the app's own figure far more often than as finished art.
