# CC0 media for rewards and the path

Public-domain (CC0) interface and game art for the app's streaks, stars, badges, trophies, path, backgrounds and an original coach, with each licence read from the source's own page.

# Surveys

* [Kenney UI, icon and game-art packs](/cc0-media/kenney.md) - Kenney's CC0 packs (Game Icons, Medals, UI Pack, Particle Pack, Background Elements, Map Pack, Shape Characters and others), what each holds for the app's rewards and path, and how well the style fits.
* [Open Peeps, Humaaans and Open Doodles](/cc0-media/open-peeps-and-related-sets.md) - Three CC0 people-illustration libraries by one illustrator, how each is built, and how far each can serve as the base for the app's original coach character.
* [Openclipart and public-domain vector mirrors](/cc0-media/openclipart.md) - Openclipart's site-wide CC0 release, its provenance flag, candidate files for trophy, flame, star, medal and rest-day art, and why mirrors such as FreeSVG and Public Domain Vectors are used only to find files.
* [OpenGameArt with the CC0 filter, and the Glitch art release](/cc0-media/opengameart-cc0.md) - How OpenGameArt's per-submission licences and CC0 filter work, the CC0 award, star, badge, face and background packs found there, and the CC0 art from the game Glitch.
* [Open art that is not CC0](/cc0-media/non-cc0-near-misses.md) - Sets met during the CC0 search that need attribution, share-alike or a custom licence, and when the app may still use them.

# Reference

* [CC0 art shortlist for rewards and the path](/cc0-media/shortlist.md) - For each piece of reward and path art the app needs, the CC0 candidates with their pack or file pages, a style-fit note, and whether it must be drawn instead.

# Recommendation

* [One style for reward and path art](/cc0-media/recommendation.md) - Use Kenney's CC0 packs as the single base family, redrawn as SVG in the app's own tokens, fill the gaps with drawn art in the same rules, and draw an original coach; no attribution duty, no league or store art.
