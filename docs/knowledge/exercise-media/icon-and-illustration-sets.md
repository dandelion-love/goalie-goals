# Summary

Icons and emoji are well covered by permissive or CC sets. Tabler (MIT) suits interface icons; OpenMoji (CC BY-SA 4.0) has the playful soccer, glove, goal-net, stopwatch, fire and trophy glyphs a game-like app wants. CC0 character sets give friendly human figures to build on. Wikimedia Commons has some exercise drawings, but every file has its own licence and must be checked one by one. Openverse is a search tool, not a licence source.

# Wikimedia Commons

- **What:** a large media library with some exercise drawings and silhouettes. Licences differ file by file: for example a squat drawing under CC BY-SA 3.0, a crunch drawing under CC BY-SA 4.0, and a silhouettes sheet in the public domain.[^commons-squats][^commons-crunch][^commons-silhouettes]
- **Rules:** check each file's own licence page; credit the creator (not the uploader) in the form the creator asks; follow share-alike; the foundation gives no warranty on licence accuracy.[^commons-reuse]
- **People:** personality rights apply on top of copyright, so an identifiable person's photo may need that person's consent for some uses.[^commons-reuse][^commons-people] The app avoids Commons photos of people entirely and only considers drawings.
- **Fit:** usable per file for a few drawings or diagrams; too uneven in style to be the main source.

# Openverse

Openverse searches openly licensed media across many sites. It does not own the content and does not verify licences or the attribution it generates; users must verify at the source.[^openverse-about][^openverse-tos] It is used only to find candidates; the licence is always taken from the source page, never from Openverse.
