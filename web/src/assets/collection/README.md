# Collection artwork provenance

These original AI-generated illustrations were created for this project using OpenAI image generation in November 2026. They are decorative and do not replace the approved exercise instructions. The initial set received independent visual review before inclusion; the review also checked movement depictions against the applicable cards.

In the keeper collection, other approved exercise cards use their versioned figure. Equipment without reviewed art uses a text fallback. A failed illustration falls back to the approved exercise figure when one is available, and then to a named text card.
